# 小红书达人 Excel 工具 2.0.2

批量转换小红书笔记长链接，并回填曝光、阅读、点赞、收藏、评论。使用 C# / .NET 10 / WPF / WebView2，面向 Windows 10/11 x64。

| 功能 | 处理内容 |
| --- | --- |
| 更新五项数据 | 蒲公英曝光、阅读和小红书三项互动数据 |
| 只更新点赞、收藏、评论 | 不访问蒲公英 |
| 发布长链接转短链接 | 官方短链转换，并核验跳转笔记 ID |
| 转短链并更新五项数据 | 先处理链接，再回填五项数据 |

## 运行

将构建得到的便携目录完整发送给使用者，解压后双击 `DarenTool.exe`。便携版包含 .NET，不依赖 Python、Node.js 或浏览器扩展。
需要系统共享 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/#download-section)，缺少时需补装。
首次在工具内登录小红书；五项模式还需登录蒲公英，在笔记报告的“报备品牌”中选择品牌并点击“查询”。上方统计区的“合作品牌”不代替该筛选。

输入为 `.xlsx`，工作表名为 `达人数据更新`，前 30 行内包含相应列名：达人、发布链接、曝光、阅读、点赞、收藏、评论。三项模式无需曝光/阅读列，只转短链只要求发布链接列。
数据按笔记 ID 匹配；原文件不覆盖。详细流程见 [开始使用.txt](开始使用.txt)。

## 构建

安装 .NET 10 SDK 后运行：

```powershell
.\build.ps1 -Edition Both
```

可以传 `-DotnetPath` 指定 SDK 的 `dotnet.exe`，或使用 PATH 中的 .NET 10 SDK。

- `dist/便携版/DarenTool.exe`：自包含 .NET 的单文件，约 62 MB。
- `dist/精简版/DarenTool.exe`：约 1.3 MB，需系统安装 .NET 10 Desktop Runtime x64。

两版均依赖系统 WebView2；上述大小不包含共享运行时和使用后缓存。`-OutputSuffix '_2.0.2'` 可发布到带版本号的目录。
构建命令只编译发布，不启动程序或运行测试。依赖版本固定，包含 `packages.lock.json`。
仓库只跟踪源码与说明，`dist/`、`bin/`、`obj/` 不提交。

## 代码结构

```text
src/DarenTool/
  MainWindow.xaml(.cs)       主窗口、模式、取消与结果展示
  Browser/BrowserSession.cs  独立官方网页会话、采集、分页校验
  Browser/bridge.js          页面请求响应观察与页面签名调用
  Core/WorkbookFile.cs       ZIP/XML 局部工作簿修改
  Core/ProcessingService.cs  四种模式、明细、缓存、原子导出
  Core/Models.cs             数据模型、链接及数量解析
```

账号配置保存在 `%LOCALAPPDATA%\DarenToolV2`，与分发文件分离。
源码不含账号、Cookie、品牌业务数据及旧版缓存。

## 采集设计

蒲公英：用户在内置官方页面登录、选择品牌并查询。页面观察器关联请求筛选和响应，工具刷新后获取全部分页。
优先使用页面实时签名调用报表接口，失败时使用真实页面分页按钮。校验品牌 ID、页码、页长、总数、冲突数据，未完整取得报表时整份曝光/阅读不参与回填。

小红书：优先复用官方网页会话签名请求笔记接口；失败时打开笔记网页兜底，接口响应或官方初始状态返回目标笔记数据后即继续，不等待完整导航完成。连续两次接口不可用后本次任务暂停直接接口尝试，避免逐行重复试错。登录/验证/限流提示暂停互动采集。必须核对笔记 ID，不从页面上任意数字猜测指标。
短链：调用官方接口，使用页面实时签名和同一浏览器会话，保留 original_url 参数，逐跳验证官方域名与笔记 ID。

浏览器脚本通过 WebView2 注入，不是浏览器扩展。不开放远程调试端口，不导入外部浏览器 Cookie，不重放已捕获的 X-s/X-t。

2.0.1 请求以开始时间间隔限速，网络时间计入 1.2 秒间隔；复用本次完整三项笔记结果与短链解析结果。逐行 JSONL 即时追加，完整快照按两秒或十行保存，并在结束/取消时强制保存。日志增加路径与耗时。未运行性能或业务测试。

## Excel 保留策略

按列名定位。仅修改目标工作表及必要超链接关系；数值更新时设置工作簿自动重算。其他 ZIP 部件内容原样复制。
原文件哈希在开始及导出时核对，不覆盖原文件。临时文件完成后再原子移动为结果文件。
目标公式拒绝覆盖；缺少的数值保留原值，零值仅来自实际返回。

## 当前状态

2.0.2 修复官方笔记错误页被误报为超时，以及失败行采集途径被标为“未请求”的问题。单篇笔记不可访问时保留缺失指标，并继续处理其他笔记。

使用者已反馈便携包可在其他电脑运行；已有用户实际采集记录。本项目尚未执行系统化的自动测试与跨版本兼容测试，网站签名入口、登录和报表结构变化仍可能需要适配。
平台明确拒绝访问的笔记不会补零或猜测数据。曝光、阅读取决于账号品牌报表权限及后台数据日期。
