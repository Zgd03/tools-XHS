达人 Excel 工具 2.0.2 · 修复开发版，待用户实测

启动：解压收到的便携包，双击同目录 DarenTool.exe。源码构建后默认位于 dist\便携版；版本号目录也可直接启动。退出已打开的旧版窗口后再启动。
便携版包含 .NET 运行时，无需 Python、Node.js 或浏览器扩展。
精简版位于 dist\精简版，需要系统已安装 .NET 10 Desktop Runtime x64。
两种版本都使用系统共享的 Microsoft Edge WebView2 Runtime；若提示缺失，从微软安装 Evergreen Runtime：
https://developer.microsoft.com/microsoft-edge/webview2/#download-section
不需要安装整个 Edge 浏览器，也不需要在 Edge/Chrome 中配置插件。

首次使用
1. 点击“小红书登录”，在工具打开的官方页面中扫码或登录。等待首页笔记加载后，点击“完成，返回主窗口”。
2. 五项模式还需点击“蒲公英登录 / 选择品牌”。进入“我的数据 → 笔记报告”，在报告列表的“报备品牌”选择品牌，点击“查询”。
   请清除其他笔记、项目、日期或关键词筛选；工具识别品牌后返回主窗口。
   “读取当前品牌”只确认当前查询的品牌和后台总条数；正式处理时再获取全部分页，避免重复读取。
3. 选择 .xlsx 文件或拖入窗口；选择结果保存目录和处理模式。
4. 点击“开始处理”。需要验证码时打开对应登录窗口，在官方页面自行完成。
5. 完成后点击“打开本次结果”，核对结果表和 CSV 明细。

处理期间不要在内置浏览器中切换品牌、翻页或打开其他笔记，以免影响采集。
登录窗口可以返回主窗口，工具会保留会话。无需将浏览器窗口关闭。
首次没有登录时，请先完成上述登录步骤再开始处理。

Excel 要求
工作表名：达人数据更新。
前 30 行内的表头，列名准确匹配；列顺序可以变化。
五项模式：达人、发布链接、曝光、阅读、点赞、收藏、评论。
三项模式：达人、发布链接、点赞、收藏、评论。
只转短链只要求“发布链接”列。
指标单元格可以为空，目标指标含公式时会停止；发布链接含公式时跳过转链。
按笔记 ID 匹配，不按达人昵称搜索。昵称和链接对应关系由用户核对。
不能输入 .xls、CSV、加密工作簿。

输出
原文件不覆盖，每次生成独立时间目录。
短链转换会同时改动文字和可点击地址，并保留原长链访问参数；仅在跳转笔记 ID 核验通过后回填。
已有短链跳过转换，仍参与指标更新。
组合模式先保存“链接处理结果”，再生成“短链与五项已处理”。
曝光/阅读取决于品牌报表权限及数据日期；取不到的字段保留原值。
“1.1万”等缩写按 11000 写入，不代表获得了更高精度；缺少的数量不会自动补零。
没有取得可写入修改时只保存明细与日志，不生成重复工作簿。
“本次采集结果.json”保留已取得的逐行结果；它不包含浏览器 Cookie，但含业务链接和数据。
“逐行采集记录.jsonl”每完成一行立即追加保存；CSV 和完整 JSON 约每两秒或十行保存一次，结束或取消时立即保存完整结果。
取消任务会保存已完成结果；取消不会立即中断正在写入的工作簿。
选择“继续上次采集”可复用同文件、同模式一小时内的完整互动数据；蒲公英报表会重新获取。

本地数据
新版不读取、不复制旧版的账号、缓存或 Excel。
登录和缓存：%LOCALAPPDATA%\DarenToolV2。
单文件 .NET 会在用户临时目录展开所需原生组件，WebView2 会生成浏览器资料；EXE 不是运行时的全部磁盘占用。
如需重置登录，先退出程序，再删除该目录下 Browser\Xhs 或 Browser\Pgy。
主窗口“清理网页缓存”仅清理已打开会话的磁盘网页缓存，保留登录资料；任务执行期间不可清理。
设置与采集缓存均在新版目录中，原便携版保持不变。

开发版限制
本版本仅完成编译发布，未启动应用或运行整表功能测试，未读取登录资料；已对一条问题短链作未登录的定点跳转诊断。
网站登录兼容性、页面签名入口、蒲公英按钮和分页结构，均待用户实际验证。
页面签名入口不可用时，蒲公英尝试官方页面翻页；短链转换会明确报告失败并保留原链接。
2.0.1 优化：互动数据优先调用笔记接口，失败再用网页兜底；网页取得对应 ID 的数据后即继续，不等待所有图片或媒体加载。
请求开始间隔至少 1.2 秒，网络耗时计入间隔；不再每行额外等待 1.2 秒。连续两次接口尝试不可用后，本次任务暂停接口尝试，使用网页兜底。
收到明确的登录、验证、限流提示时暂停后续互动请求，曝光和阅读继续按已取得的蒲公英报表匹配。完成验证后重新开始或继续上次采集。
运行日志记录每行耗时、链接解析耗时和采集途径，便于比较实际性能；未宣称已验证提速倍数。
2.0.2 修复：识别官方笔记错误页，及时显示平台错误码与提示；修复失败行“未请求”的错误日志；明确不可访问的单篇笔记不影响其他笔记继续采集。
单文件 EXE 尚未购买代码签名证书，Windows 可能提示未知发布者。
遇到问题请提供操作模式、错误提示、运行日志，以及必要的脱敏表头；不要提供登录资料或浏览器缓存。
